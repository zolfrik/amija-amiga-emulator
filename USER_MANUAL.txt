===============================================================================
 1.  ABOUT AMIJA
===============================================================================

  AmiJa is a cycle-exact Amiga emulator written in Java. CPU, custom chips,
  CIAs and floppy drives run on a common 7.09 MHz master clock.

    *  OCS, ECS and AGA chipsets (AGA on an emulated A1200), PAL and NTSC
    *  68000, 68010 and 68020 processors
    *  Chip, Slow and Fast RAM; up to four floppy drives
    *  ADF, IPF and ZIP disk images
    *  Hard disk images (.hdf) on a Zorro II AutoConfig controller
    *  WHDLoad archives (.lha, .lzh) started directly
    *  Software or OpenGL rendering with RetroArch shaders (.glslp, .slangp)
    *  Five save-state slots, rewind, screenshots, real joysticks, drive sounds
    *  Remote play for a second player and spectators
    *  Output to a real 15 kHz CRT through a MiSTer FPGA (Groovy core)
    *  Automatic mode: the machine is configured from the loaded media

  The configuration is stored in amiga.properties and can be edited by hand
  or from the F12 popup.


===============================================================================
 2.  GETTING STARTED
===============================================================================

  Without a Kickstart, AmiJa uses its own built-in ROM. It boots floppy games
  that load themselves from the boot block, but provides no AmigaDOS:
  Workbench, hard disks and WHDLoad require a real Kickstart. Kickstart is
  copyrighted and not included; it is available with Amiga Forever
  (amigaforever.com) or can be dumped from an Amiga you own.

  Press F12, set "Kickstart 1.3" and, for hard disk, WHDLoad and AGA software,
  "Kickstart 3.1" (preferably the A1200 release 40.68). Press OK to boot.

  ---------------------------------------------------------------------------
  2.1   FILES AND FOLDERS
  ---------------------------------------------------------------------------

  All paths are relative to the AmiJa home: the folder containing AmiJa.exe,
  bin/AmiJa or AmiJa.jar. When started from an IDE or Maven, the working
  directory is used instead. The home folder must be writable; do not install
  under Program Files or /opt.

    amiga.properties     configuration; created with defaults if missing
    shaders/             shader presets (*.glslp, *.slangp), subfolders included
    shaders/shaders_slang/
                         slang layout and shared include files; see
                         shaders/Mega_Bezel_Packs/readme.txt
    blurs/               blur passes used by some presets
    screenshots/         screenshots (PNG)
    savestate/           Slot1/ ... Slot5/, each with state.a5s and state.png
    whdload-saves/       persistent WHDLoad saves (WHDSaves: volume)
    floppysounds/        drive sound samples; replaceable, empty to silence
    whdload/             WHDLoad system files and .RTB tables; shipped empty,
                         filled by the download assistant (3.14)

  ---------------------------------------------------------------------------
  2.2   KEYBOARD AND MOUSE
  ---------------------------------------------------------------------------

    F12                     open the configuration popup (pauses emulation)
    Left / Right Alt        left / right Amiga keys (Windows keys also work)
    Page Up / Page Down     left / right Amiga Alt
    Home                    Amiga HELP
    Ctrl + Amiga + Amiga    hard reset (on release)

    Left mouse button       capture the mouse
    Middle mouse button     release the mouse (also released on focus loss)
    Right mouse button      Amiga right button

    Drag and drop           insert a disk image. The window is split into four
                            quadrants: top-left DF0, top-right DF1, bottom-left
                            DF2, bottom-right DF3.

  Keys held down are released automatically when the window loses focus.


===============================================================================
 3.  THE F12 POPUP
===============================================================================

  F12 pauses emulation, releases the mouse and opens the configuration popup.
  Sections, in order:

    System (3.2)
    Drives (3.3)                               automatic mode
    Floppy drives, Hard disks, WHDLoad         expert mode (3.4 - 3.6)
    Saved state (3.7)
    Rewind (3.8)
    Game ports (3.9)
    Remote play (3.10)
    MiSTer (Groovy) (3.11)
    Audio / Video (3.12)
    GUI (3.13)
    Optional files (3.14)                      hidden once all is installed

  Saved state, Rewind, Game ports, Remote play, MiSTer (Groovy), Audio /
  Video and GUI are collapsible and closed by default; the open ones are
  remembered in ui.popup.expanded.

  When joining or watching a remote session, System, the drive sections,
  Saved state, Rewind and MiSTer (Groovy) are hidden.

  ---------------------------------------------------------------------------
  3.1   CONVENTIONS
  ---------------------------------------------------------------------------

  Each setting lists its amiga.properties key, its values and when it takes
  effect:

    LIVE       applied on OK; the machine keeps running.
    RESTART    the machine is rebuilt automatically on OK.
    RELAUNCH   AmiJa restarts itself on OK.
    BOOT       applied at the next Restart or launch.

  ESC cancels, ENTER confirms. File browsers save the last folder immediately,
  even if the popup is cancelled.

  If the configuration cannot start (for example a 68020-only Kickstart on a
  68000, or Kickstart 1.x with a hard disk or WHDLoad), AmiJa reports the
  conflict and asks for a correction instead of booting.

  ---------------------------------------------------------------------------
  3.2   SYSTEM
  ---------------------------------------------------------------------------

  Expert mode                                                   auto.enabled
     Unticked (default): automatic mode. The machine is configured from the
     loaded media using one of three profiles (4.2):

       Floppy            Kickstart 1.3, OCS, 68000, 512 KB Chip + 512 KB Slow
       Hard disk/WHDLoad Kickstart 3.1, ECS, 68010, 2 MB Chip + 8 MB Fast
       AGA               Kickstart 3.1, A1200 (AGA, 68020, 2 MB Chip);
                         8 MB Fast with hard disk or WHDLoad

     The AGA profile is used when the WHDLoad slave requires AGA or a file
     name contains the word "AGA" (e.g. "(AGA)", "_AGA.lha"). A WHDLoad slave
     that requires a 68020 gets one in any profile. A file name containing
     "NTSC" or "(USA)" selects NTSC; otherwise PAL. In automatic mode the
     machine rows show the deduced values and are read-only.

     Ticked: every setting is manual and the Drives list is replaced by
     sections 3.4 - 3.6. Manual settings are preserved while automatic mode
     is active.

     Note: ticking the box writes auto.enabled=false.
     Values: true / false (default true)                        Applies: BOOT

  Kickstart 1.3 / Kickstart 3.1          auto.kickstart13.path / .kickstart31.path
     ROMs used by automatic mode: 1.3 for floppy, 3.1 for hard disk, WHDLoad
     and AGA. For 3.1, use the A1200 release (40.68): some AGA WHDLoad slaves
     reject 40.63. If one is empty, the other is used, then kickstart.path,
     then the built-in ROM.
     Values: absolute path or empty                             Applies: BOOT

  Kickstart                                                   kickstart.path
     ROM used in expert mode. Any power-of-two image up to 512 KB. Headers,
     appended data and duplicated halves are normalised; CDTV extended ROMs
     and ReKick images are rejected with an explanation.
     Values: absolute path                                      Applies: BOOT

  Processor                                                        cpu.model
     68000; 68010 (vector base register, loop mode, MOVEC/MOVES/RTD;
     MOVE from SR is privileged, which stops a few 68000 games); 68020
     (32-bit, the A1200 processor, much faster).
     Values: 68000E / 68010E / 68020 (68000 and 68010 also accepted)
                                                             Applies: RESTART

  Chipset                                                            chipset
     OCS: original chipset. ECS: enhanced Agnus/Denise (BEAMCON0, DIWHIGH,
     BPLCON3, super-hires, productivity modes). AGA: builds a full A1200
     (Alice, Lisa, Gayle; 8 bitplanes, 24-bit palette, HAM8); requires
     Kickstart 3.1, 2 MB Chip RAM and the 68020.
     Values: OCS / ECS / AGA                                 Applies: RESTART

  Chip RAM                                                        chipram.kb
     Values: 256 / 512 / 1024 / 2048 (KB)                       Applies: BOOT

  Slow RAM                                                        slowram.kb
     Trapdoor expansion at $C00000. Not available on the A1200 (AGA).
     Values: 0 / 512 / 1024 / 1536 / 1792 (KB)                  Applies: BOOT

  Fast RAM                                                        fastram.kb
     Zorro II AutoConfig memory, no chip-bus contention.
     Values: 0 / 512 / 1024 / 2048 / 4096 / 8192 (KB)           Applies: BOOT

  Video mode                                                      video.mode
     PAL (50 Hz, 312 lines) or NTSC (60 Hz, 262 lines).
     Values: PAL / NTSC                                      Applies: RESTART

  ---------------------------------------------------------------------------
  3.3   DRIVES (AUTOMATIC MODE)
  ---------------------------------------------------------------------------

  A single list of media. Each added file is assigned automatically:

    DF0: - DF3:           floppy images (.adf, .ipf, .zip), in order added;
                          DF0 boots
    Hard drive master     first .hdf
    Hard drive slave      second .hdf
    WHDLoad               .lha or .lzh archive

  Limits: four floppies, two hard disks, one WHDLoad archive; a hard disk and
  a WHDLoad archive cannot be combined. Unsupported or excess files are
  rejected with the reason. Entries marked with an asterisk need hardware the
  running machine does not have and are mounted at the next start.

  The rows write the same keys as expert mode (drive.dfN.disk,
  hd.master.disk, whdload.file, ...).
  Applies: LIVE for floppies in existing drives, BOOT otherwise

  ---------------------------------------------------------------------------
  3.4   FLOPPY DRIVES (EXPERT MODE)
  ---------------------------------------------------------------------------

  DFn connected                                            drive.dfN.enabled
     Drive present. DF0 and DF1 are connected by default.
     Values: true / false                                       Applies: LIVE

  Disk path                                                   drive.dfN.disk
     .adf   sector image
     .ipf   flux-level image of an original disk, copy protection included
     .zip   compressed image; a multi-disk archive fills DF0 and the next
            free drives (<archive>.zip!<n>); always write-protected

     Changing a disk on a running machine ejects the old one and inserts the
     new one about 1.5 s later, so the Kickstart detects the change.
     Values: absolute path or empty                             Applies: LIVE

  Padlock                                                 drive.dfN.readonly
     Closed: write-protected. Open: writes are saved to the image file.
     Values: true / false                                       Applies: LIVE

  Eject
     Clears the path; the disk is ejected on OK.

  ---------------------------------------------------------------------------
  3.5   HARD DISKS (EXPERT MODE)
  ---------------------------------------------------------------------------

  Master and slave units on a Zorro II AutoConfig controller whose boot ROM
  provides OFS/FFS.

  Master / Slave                         hd.master.enabled / hd.slave.enabled
     Values: true / false                                       Applies: BOOT

  Image path                                   hd.master.disk / hd.slave.disk
     Values: absolute path to .hdf or empty                     Applies: BOOT

  Padlock                              hd.master.readonly / hd.slave.readonly
     Hard disks are writable by default.
     Values: true / false                                       Applies: BOOT

  ---------------------------------------------------------------------------
  3.6   WHDLOAD (EXPERT MODE)
  ---------------------------------------------------------------------------

  Auto-run WHDLoad archive                   whdload.enabled / whdload.file
     The archive is extracted into a bootable FFS hard disk together with the
     WHDLoad system files and started. Requires the WHDLoad files (3.14).
     Saved games are kept in whdload-saves/. WHDLoad options are set in
     whdload.prefs.* (4.7). Most titles need 1 MB or more of Chip RAM and
     some Fast RAM.
     Values: true / false; absolute path to .lha or .lzh        Applies: BOOT

  ---------------------------------------------------------------------------
  3.7   SAVED STATE
  ---------------------------------------------------------------------------

  Five slots, one tab each (savestate/Slot1/ ... Slot5/). Each tab shows a
  thumbnail and the save date; a dot in the tab title marks a used slot. The
  selected tab is stored in savestate.slot.

    Save State     save the machine to the selected slot (overwrites it)
    Load State     restore the selected slot
    Clear Slot     delete the selected slot (after confirmation)

  Each slot stores the configuration it was saved with. Loading a slot saved
  with different hardware or media restores that configuration and rebuilds
  the machine first. States from an incompatible version are rejected.
  A legacy savestate/state1.a5s is migrated to Slot 1 automatically.

  ---------------------------------------------------------------------------
  3.8   REWIND
  ---------------------------------------------------------------------------

  History to keep                                             rewind.seconds
     AmiJa keeps one snapshot per second of play, in memory. Lengths that
     exceed the memory available for the history are disabled; the maximum
     is shown next to the list.
     Values: 0 (off) / 30 / 60 / 120 / 300 / 600 (default 60)  Applies: LIVE

  Rewind bar
     Drag left to choose a moment; the preview shows the screen at that
     point. OK resumes from there and discards what followed; Cancel leaves
     the game unchanged. If settings requiring a restart were also changed,
     AmiJa asks whether to rewind or restart.

  ---------------------------------------------------------------------------
  3.9   GAME PORTS
  ---------------------------------------------------------------------------

  Port 0 / Port 1                     input.port0.device / input.port1.device
     Port 0 is the mouse port, Port 1 the joystick port.

       Mouse                 host mouse                       mouse
       Joystick (real)       physical joystick or gamepad     joystick-real
       Joystick (keyboard)   keyboard-emulated joystick       joystick-keyboard
       Empty                 nothing connected                none

     "Joystick (keyboard)" shows a "..." button for the key mapping (3.15.1).
     During a remote session only your own port can be set.
     Applies: LIVE

  ---------------------------------------------------------------------------
  3.10   REMOTE PLAY
  ---------------------------------------------------------------------------

  The host runs the emulation and streams video and audio; the guest sends
  back the controls for one game port. The guest needs no Kickstart and no
  copy of the game. Spectators receive video and audio only.

  Latency affects the guest only: about one frame on a local network, about
  three frames over a good Internet connection. One guest per session.

  Mode: Off / Host / Join / Watch
     Not saved; AmiJa always starts with no session.

  HOSTING

  Port                                                       remoteplay.port
     TCP and UDP port.
     Values: 1-65535 (default 7788)                  Applies: on start hosting

  Open the port on the router (UPnP)                         remoteplay.upnp
     Requests port forwarding from the router and removes it when hosting
     stops. Not used when "Local network only" is set.
     Values: true / false (default true)             Applies: on start hosting

  Local network only                                     remoteplay.lan.only
     Rejects connections from outside the local network.
     Values: true / false (default true)             Applies: on start hosting

  Start hosting / Stop hosting
     Starts or ends the session. The local game is not affected.

  Address / Internet / Join code / Spectator code
     Information to give to the other players. "Internet" appears once the
     router confirms the forwarding, or shows why it failed. The join code
     is the session password: regenerated each time, never saved, never sent
     in clear, and used to derive the encryption keys. The spectator code
     allows watching only and can be shared freely. Codes are
     case-insensitive; O/0 and I/1 are equivalent.

  Guest uses                                           remoteplay.guest.port
     Game port assigned to the guest. The guest chooses the device.
     Values: 0 / 1 (default 1)                       Applies: next connection

  Share the keyboard                               remoteplay.guest.keyboard
     Values: true / false (default true)             Applies: next connection

  The guest may reset                            remoteplay.guest.allowreset
     Allows Ctrl+Amiga+Amiga from the guest.
     Values: true / false (default false)            Applies: next connection

  Spectators                                       remoteplay.spectators.max
     Maximum number of spectators besides the guest. Each costs about as much
     upload as the guest (0.5 - 2.5 Mbit/s, up to 5). Under load, spectators
     receive fewer frames first.
     Values: 0 - 16 (default 4; 0 = none)            Applies: next connection

  Audio                                                remoteplay.audio.mode
       Compressed (355 kbit/s)     IMA-ADPCM         adpcm
       Uncompressed (1.4 Mbit/s)   16-bit PCM        pcm16
       Off                         no audio          off
     The audio filter is applied by the host.
     Values: adpcm / pcm16 / off (default adpcm)     Applies: next connection

  JOINING AND WATCHING

  Host address / Join code                              remoteplay.last.host
     The host's address:port and the join code (to play) or spectator code
     (to watch). The address is remembered; the code is not.

  Connect / Disconnect
     Connects while the popup stays open; the Status line reports progress.
     On OK this computer stops emulating and becomes a remote display.
     Disconnect restores the local machine.

  Status
     Connection state, traffic counters and the reason for the last failure.

  TROUBLESHOOTING

    "Your provider does not give you a public address (CGNAT)"
        The host cannot be reached from the Internet. Swap host and guest.
    "No router answered" / "The router refused to open the port"
        Enable UPnP on the router or forward the port manually.
    "port opened by the router. If nobody can get in, it is the firewall"
        Allow AmiJa through the host's firewall.
    "nothing is listening on that port" / "that address does not exist"
        Check the address and that hosting has started.
    "no answer - address, port or firewall"
        Usually the host's firewall or a missing forwarding.
    "the host only accepts players on its own local network"
        The host has "Local network only" enabled.
    "every spectator place is taken" / "the host does not accept spectators"
        Spectator limit reached, or set to 0.
    "wrong join code"
        Codes change at every start; ask for the current one.
    "the two machines run different versions of AmiJa"
        Both sides must run the same version.

  Remote play and the MiSTer output (3.11) cannot run together.

  ---------------------------------------------------------------------------
  3.11   MISTER (GROOVY)
  ---------------------------------------------------------------------------

  Sends the picture and the sound over Ethernet to a MiSTer FPGA running the
  Groovy core, which shows them on a 15 kHz CRT (for example SCART RGB) with
  its own analogue output. The PC keeps emulating; the MiSTer is only the
  screen, with less than a frame of delay. The emulation follows the MiSTer's
  raster, PAL or NTSC, interlaced modes included.

  Requirements: the Groovy core loaded on the MiSTer before pressing Start,
  and a wired connection (direct cable or switch). Over Wi-Fi the picture
  breaks up. The output cannot run together with remote play (3.10).

  While the output runs, the LED panel shows a MISTER light, lit while the
  MiSTer is receiving the picture.

  Settings                                                     mister.expert
     Expert mode shows Colour, Compression, Sound and Position as well.
     Values: true / false (default false)                       Applies: LIVE

  Output: Start / Stop
     Starts or stops sending. The output never starts by itself: press Start
     every time AmiJa is launched. On a failure it keeps retrying every
     2 seconds and the Status line says why.

  MiSTer address                                                 mister.host
     The MiSTer's IP address. Empty: searched on all the PC's networks each
     time the output starts, preferring a direct cable. "Search" lists the
     MiSTers that answer and writes the address of the one chosen.
     Values: IP address, or empty (default)                 Applies: on Start

  Controls                                                     mister.inputs
       PC        the PC's mouse, keyboard and joysticks (default)     pc
       MiSTer    the devices plugged into the MiSTer                  mister
     With MiSTer, each game port (3.9) takes the matching MiSTer device: its
     mouse, its joysticks (the first one to the first port set to a real
     joystick), or its keyboard with the keyboard joystick keys; the rest of
     its keyboard is the Amiga keyboard, and the PC's controls are ignored.
     Joystick button 1 is fire, buttons 2 and 3 the second and third; which
     physical button is which is set in the MiSTer menu (Define buttons). The
     Groovy core sends them only when PS2 and Joysticks are enabled in its
     menu, which takes effect when the core is reloaded.
     Values: pc / mister                                    Applies: on Start

  Colour (expert)                                               mister.color
       Auto      16 bit for OCS/ECS, 24 bit for AGA (default)     auto
       16 bit    RGB 565                                          565
       24 bit    RGB 888                                          888
     24 bit on OCS/ECS changes nothing on screen and costs more traffic.
                                                            Applies: on Start

  Compression (expert)                                    mister.compression
       LZ4 delta      only what changed since the last frame      lz4delta
       LZ4            whole frames, compressed                    lz4
       Uncompressed   about 165 Mbit/s, needs a gigabit link      raw
     Values: lz4delta / lz4 / raw (default lz4delta)        Applies: on Start

  Sound (expert)                                 mister.audio / .audiolead
     "On the MiSTer" plays the sound through the MiSTer's output; while the
     MiSTer does not play it (not connected, or audio off in the core menu)
     it plays on the PC. The number is how far ahead of the picture the MiSTer
     holds the sound, in milliseconds: raise it if the sound crackles, at the
     cost of the same delay on what you hear.
     Values: true / false (default true); 10 - 150 (default 40)
                                                            Applies: on Start

  Position (expert)                               mister.hshift / .vshift
     Shift of the picture on the tube, to centre it while watching the TV.
     Values: -64 - 64 pixels; -20 - 20 lines (default 0)        Applies: LIVE

  Status
     Whether the MiSTer is receiving the picture and, if not, why.

       on     PAL 724x576     NTSC 724x480

  Floppy sound volume                                    floppy.sound.volume

     Values: 0 - 10                                             Applies: LIVE

  ---------------------------------------------------------------------------
  3.15   SUB-DIALOGS
  ---------------------------------------------------------------------------

  3.15.1   KEYBOARD JOYSTICK KEYS

     One row per direction and Fire. Click a button and press the new key;
     ESC cancels (and cannot be assigned). A key can serve only one function
     across both ports. "Reset to defaults" restores the port's keys.

       Port 0    W A S D, right Ctrl
       Port 1    arrow keys, left Ctrl

     Keys: input.portN.joystick.up / down / right / left / fire
     Values: KeyEvent VK_ name without prefix (W, UP, SPACE, NUMPAD5); for
     duplicated keys append the side (CONTROL:LEFT, SHIFT:RIGHT).
     Applies: LIVE

  3.15.2   SHADER PARAMETERS

     One slider per "#pragma parameter" of the preset, applied immediately.
     Values are saved as <preset>.params next to the preset.

  ---------------------------------------------------------------------------
  3.16   BUTTON BAR
  ---------------------------------------------------------------------------

    About             version, author and project page
    Take Screenshot   saves the emulated picture to
                      screenshots/screenshot_<date>_<time>.png
    Soft Reset        saves the configuration and resets the CPU; memory is
                      preserved
    Restart           saves the configuration and rebuilds the machine (cold
                      start)
    Quit              writes pending hard disk changes and exits; unconfirmed
                      edits are discarded
    Cancel (ESC)      closes the popup and discards edits
    OK (ENTER)        saves and applies; restarts the machine if needed

 4.  PROPERTIES AVAILABLE ONLY IN amiga.properties
===============================================================================

  Edit with the emulator closed, or the next save overwrites the changes.
  Escape backslashes in Windows paths (C:\\Amiga\\...).

  ---------------------------------------------------------------------------
  4.1   FILE BROWSER FOLDERS
  ---------------------------------------------------------------------------

    chooser.media.lastDirectory       Drives list
    chooser.floppy.lastDirectory      floppy browser
    chooser.rom.lastDirectory         Kickstart browser
    chooser.hdf.lastDirectory         hard disk browser
    chooser.whdload.lastDirectory     WHDLoad browser

  Maintained by AmiJa. Values: absolute path or empty.

  ---------------------------------------------------------------------------
  4.2   AUTOMATIC-MODE PROFILES
  ---------------------------------------------------------------------------

  Hardware built by each automatic-mode profile (3.2).

    Property                 Floppy        Hard disk/WHDLoad    AGA
    ------------------------------------------------------------------------
    auto.*.chipram.kb        512           2048                 2048
    auto.*.slowram.kb        512           512                  0
    auto.*.fastram.kb        0             8192                 8192 (1)
    auto.*.chipset           OCS           ECS                  AGA
    auto.*.cpu               68000E        68010E               68020

    Prefixes: auto.floppy., auto.hd., auto.aga.
    (1) Only with a hard disk or WHDLoad archive.

  Values as in 3.2. Applies: BOOT

  Profile selection: AGA when the WHDLoad slave requires it or a file name
  contains "AGA" as a word; hard disk when a hard disk or WHDLoad archive is
  active; floppy otherwise. A slave requiring a 68020 always gets one. Video
  mode: NTSC when an active file name contains "NTSC" or "(USA)" (file name
  only, not folders), PAL otherwise.

  4.3   REMOTE PLAY
  ---------------------------------------------------------------------------

    remoteplay.bind
        Local IP address to listen on when hosting; empty = all interfaces.
        Applies: on start hosting

    remoteplay.last.host
        Last address joined. Maintained by AmiJa.

  ---------------------------------------------------------------------------
  4.4   MISTER
  ---------------------------------------------------------------------------

    mister.bind
        Local IP address to send from; empty = the network card on the
        MiSTer's subnet.

    mister.mtu
        Link MTU. 1500 (default) for an ordinary network; larger only if both
        ends use jumbo frames.

  Applies: on Start

    overlay.fps.enabled             host frames per second (bottom left)

  4.6   BLITTER
  ---------------------------------------------------------------------------

    blitter.immediate

        Values: true / false (default false)                    Applies: BOOT

===============================================================================
 6.  COMMAND LINE
===============================================================================

      AmiJa [options] [file ...] [key=value ...]
      java -jar AmiJa.jar [options] [file ...] [key=value ...]

  file              Media to load: floppy (.adf, .ipf, .zip), hard disk
                    (.hdf) or WHDLoad archive (.lha, .lzh), assigned as in
                    the Drives list (3.3). When files are given, they replace
                    all configured media. Same limits as 3.3. A missing file
                    aborts the launch.

  key=value         Sets any property from chapter 5 for this session; it
                    overrides what the files determine. An empty value clears
                    the property. The last occurrence wins. Quote arguments
                    containing spaces.

  --config FILE     use FILE instead of amiga.properties (created if missing)
  --home DIR        set the application home
  --print-config    print the resulting configuration and exit
  --help, -h        print help and exit

  Command-line values are not saved to amiga.properties; only settings
  changed in the F12 popup during the session are. Unknown keys or
  malformed arguments exit with status 2 and a message on standard error.
  All values take effect immediately.

  In automatic mode Kickstart, memory, chipset and processor follow the
  media; pass auto.enabled=false to set them explicitly.

  Examples:

      AmiJa "C:\Games\Turrican II (Disk 1).adf" "C:\Games\Turrican II (Disk 2).adf"
      AmiJa /games/Lotus2.lha video.windowMode=fullscreen
      AmiJa --config C:\Frontend\a1200.properties auto.enabled=false
            chipset=AGA cpu.model=68020
